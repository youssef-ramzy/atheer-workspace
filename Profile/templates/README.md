# Profile Templates

Copy only templates you intend to use into your private workspace. Replace
placeholders with information you are comfortable sharing with the AI agent
and its provider. Remove fields that are not useful.

- [Developer profile](developer-profile.md) — optional role, stack, skills,
  goals, and collaboration context
- [Project](project.md) — scoped work goal and status
- [Study plan](study-plan.md) — a learning goal and next step
- [Reference note](reference-note.md) — source and freshness-aware knowledge

The first-use interview and automatic profile writing are not implemented.
Adding personal data is currently a manual, user-controlled choice.
