# Soul — Role and Boundaries

The soul layer describes the assistant's general role, principles, and
boundaries. It is generic starter guidance, not a personal biography or a
claim that a model has a persistent identity.

- [Identity template](identity.md) describes the assistant's role.
- [Baseline boundaries](boundaries.md) describe safe, honest behavior.
- See the [_index.md](_index.md) navigation for these files.
- Personal additions belong in an ignored `identity.local.md`; do not commit
  personal values or profile details to a shared starter.
