# Memory — Optional and User-Controlled

Atheer separates memory by purpose so an agent can load only the relevant
material. Create notes only when the user requests or approves persistence.

- [Episodic](episodic/README.md) — dated events and session records
- [Semantic](semantic/README.md) — durable concepts and approved preferences
- [Procedural](procedural/README.md) — reusable methods and workflows

This structure is not an automatic memory system. Do not bulk-read it, infer
personal facts from it, or save session history without permission.
