# Planning a Study Session

Use when the owner asks to organize a learning session or study plan.

1. Consult only the relevant study goal, current progress, and materials.
2. Ask for the topic or available time if it materially changes the plan.
3. Make a realistic, focused plan with an actionable next step.
4. Distinguish planned work from completed progress.
5. Do not claim learning progress or save a study log unless the owner asks.
6. Link the study files used and state when information is missing.
