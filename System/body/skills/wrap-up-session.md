# Wrap Up a Work Session

Use this workflow when the user asks to finish or summarize a session.

1. State what was completed and the most relevant files or decisions.
2. Report checks actually run and any remaining limitations.
3. Suggest the next action only when it helps the user continue.
4. Do not save a session log, memory, or new preference unless the user asks.
5. Do not commit, push, publish, deploy, or contact others unless the user
   explicitly requests that action and the environment supports it.

This is a written procedure, not an automatic shutdown hook.
