# Start a Work Session

Use this workflow when beginning a task in this workspace.

1. Read the root `AGENTS.md` and any instructions for the target project.
2. Clarify the task goal if it is not clear from the request.
3. Follow relevant `_index.md` files and load only context needed for this
   task. Do not scan all profile, memory, or knowledge files by default.
4. Read session continuity only when it is relevant and available. Treat it as
   potentially stale; verify important claims against current files.
5. State any material assumption before relying on it. Then begin the task.

This is a Markdown procedure. It runs only when an agent or user invokes it;
the workspace does not automatically start a session.
