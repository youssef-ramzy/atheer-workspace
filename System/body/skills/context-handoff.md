# Prepare a Context Handoff

Use this workflow when the user asks to pause, switch tools, or continue the
task in another session.

1. Summarize the task and current status in a few concrete points.
2. List decisions, changed files, verification performed, and unresolved work.
3. Identify the next useful action and any assumptions that need checking.
4. Do not copy unrelated profile details, credentials, or confidential content
   into the handoff.
5. Keep the handoff in the conversation unless the user asks to save it. If
   saving is requested, use the approved local continuity location.

Do not claim the host has cleared or transferred its context unless that
behavior is available and verified.
